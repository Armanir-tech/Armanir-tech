## Featured Projects

### SDG Policy Intelligence Agent

An agentic AI research assistant for development policy documents.

- Uploads and indexes PDF/TXT reports for retrieval.
- Uses RAG and vector search to return source-aware answers.
- Runs a LangGraph workflow for research, analysis, validation, and policy brief generation.
- Integrates multiple LLM providers through API routing.
- Includes Turkish and English UI support.
- Deployed on an Ubuntu server with FastAPI, React, Nginx, and a persistent backend service.

Repository: [sdg-policy-intelligence-agent](https://github.com/Armanir-tech/sdg-policy-intelligence-agent)  
Live demo: [http://213.142.148.196](http://213.142.148.196)

### Financial Market Direction Prediction

A university machine learning project using Yahoo Finance data to compare models for next-day financial market direction prediction during event-based market periods.

- Compares k-NN, Random Forest, LSTM, and a momentum baseline.
- Uses time-aware evaluation to avoid future-data leakage.
- Engineers financial indicators such as returns, rolling volatility, RSI, MACD, moving-average ratios, and previous-day direction.
- Evaluates results with accuracy, F1-score, heatmaps, and confusion matrices.

Repository: [financial-market-direction-prediction](https://github.com/Armanir-tech/financial-market-direction-prediction)

### Depth Map Maker

A private experimental tool for turning images into machine-ready relief assets.

- Converts source images into editable depth-map previews.
- Provides interactive refinement controls for surface, edge, and relief quality.
- Includes 3D preview, brush-based editing, and export-oriented workflow experiments.
- Focuses on practical image-to-relief production workflows while the core implementation remains private.
